[Português](VERSIONAMENTO.md) · [English](VERSIONING.en.md) · [Español](VERSIONING.es.md)

Esta clasificación retrospectiva no afirma que todos los prototipos funcionaran o se publicaran. El orden anterior a Git usa los archivos y registros locales disponibles; no reconstruye intentos sin un archivo conservado.

Se conservan etiquetas, commits, checksums y paquetes antiguos. Los ejecutables antiguos pueden mostrar su versión original; la nueva interfaz muestra **Beta 0.0.36**. Este inventario no publica archivos personales ni recompila prototipos. Los paquetes “ajustada” y “fonte-corrigida” tienen el mismo código Python listado, pero hashes diferentes; se registran por separado sin inventar una corrección de código.

**Compatibilidad:** Beta describe la etapa del producto. Las releases permanecen en el canal `/releases/latest` para conservar los actualizadores y enlaces existentes. No se convierten al filtro técnico de prerelease de GitHub, que [queda fuera de ese canal](https://docs.github.com/en/rest/releases/releases#get-the-latest-release). El actualizador usa identificadores de release y no compara 7.x con 0.x. No se reinician preferencias ni datos.
